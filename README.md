   # Face Recognition & Clustering
# 1) Алгоритм (Пайплайн):
+ Загрузка изображений:
Пользователь загружает фото через UI (Streamlit) или кладёт их в папку images.

+ Детекция лиц:
Используется модель SCRFD для поиска лиц на изображении.
На выходе: координаты рамки (bbox) и ключевые точки лица (landmarks).

+ Извлечение эмбеддингов:
Для каждого найденного лица вычисляется векторное представление (embedding) с помощью модели ResNet50 (w600k_r50.onnx).
Эмбеддинги нормализуются для корректного сравнения.

+ Кластеризация лиц:
Все эмбеддинги объединяются и группируются с помощью алгоритмов:
DBSCAN (по умолчанию)
или KMeans (альтернативный вариант).
Лица одного человека попадают в один кластер.

+ Присвоение идентификаторов:
Каждому кластеру назначается уникальный ID (person_1, person_2, …).

+ Визуализация и сохранение:
На фото рисуются рамки и подписи с идентификаторами.
Сохраняются кропы лиц по папкам.
Генерируется JSON с результатами.
В UI можно скачать ZIP с визуализированными фото и JSON.

# 2) Используемые модели:
+ SCRFD (scrfd_10g_bnkps.onnx)

+ Источник: InsightFace Model Zoo

+ Назначение: детекция лиц (рамки и ключевые точки).

+ Адаптация: запуск на CPU (ctx_id=-1), входной размер (640, 640).

+ ResNet50 (w600k_r50.onnx)

+ Источник: InsightFace Model Zoo

+ Назначение: извлечение эмбеддингов лиц.

+ Адаптация: нормализация эмбеддингов для устойчивой кластеризации.

# 3) Как работает кластеризация:
+ Алгоритм DBSCAN

+ eps = 0.6 — радиус соседства (порог схожести между лицами).

+ min_samples = 2 — минимальное число точек для образования кластера.

+ metric = cosine — метрика сравнения эмбеддингов (косинусное сходство).

+ Лица, не попавшие ни в один кластер, получают метку -1 (шум).

+ Алгоритм KMeans (альтернатива)

+ n_clusters = 5 — число кластеров задаётся вручную.

+ Используется при необходимости фиксированного количества групп.

# 4) Инструкция по запуску:
## 1. Установка зависимостей:
```python
pip install -r requirements.txt
```
## 2. Подготовка моделей:
+ Скачайте модели и положите их в папку models/:
+ scrfd_10g_bnkps.onnx: [КЛИК](https://huggingface.co/DIAMONIK7777/antelopev2/blob/main/scrfd_10g_bnkps.onnx)
+ w600k_r50.onnx: [КЛИК](https://huggingface.co/maze/faceX/blob/e010b5098c3685fd00b22dd2aec6f37320e3d850/w600k_r50.onnx)
+ Также необходимо создать папку result/ и images/
## 3. Запуск пайплайна (консоль):
+ Поместите ваши фотографии в папку images/ после чего в консоле напишите:
```python
 python main.py
 ```
+ Результаты сохраняются в папку results/:
+ results.json — метаданные (bbox, label, person_id).
+ results/crops/ — кропы лиц по папкам.
+ results/result_<filename>.jpg — визуализированные фото.
## 4) Запуск UI (Streamlit):
+ Напишите в консоле:
```python
streamlit run ui.py
```
+ После чего хагружайте фото через интерфейс.
+ Система автоматически обработает их, сгруппирует лица и покажет результат.
+ Доступна загрузка JSON и ZIP с визуализированными фото.
+ Возможно консольный запуск будет быстрее чем UI.
